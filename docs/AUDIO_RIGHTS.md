# Audio rights gate

The app streams ayah files from `https://everyayah.com/data` using the reciter directories documented in `EVERYAYAH_AUDIO.md`.

No repository evidence establishes the recording owner, reciter-specific licence, redistribution permission, or permission for permanent user downloads. Service availability and streaming access are not a redistribution grant. Consequently offline downloads, caching, and bundled recitation remain disabled.

Implementation may begin only after written terms identify each selected recording, owner, permitted territories/uses, attribution, modification rules, offline storage, redistribution, and termination obligations.

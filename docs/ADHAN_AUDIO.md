file **Beautiful adhan.ogg**, recorded and uploaded by Wikimedia Commons user
Adam-synagda.

The uploader identifies the recording as their own work and explicitly
dedicates it under CC0, which permits copying, distribution, modification,
and commercial use without requesting permission. Attribution is retained
here for provenance even though CC0 does not require it.

Android uses the stable, versioned channel ID `adhan_v1`. Channel sound
configuration is immutable after the user/device creates it; changing the
bundled sound in a later release therefore requires a deliberate new channel
version, not dynamic channel creation.

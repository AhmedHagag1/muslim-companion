# Security policy

Report suspected vulnerabilities privately to Ahmed Haggag at ahmedhaggagdev@gmail.com. Do not disclose vulnerabilities or attach backups, location, credentials or personal history to a public issue.

Include affected version/platform, reproduction steps and impact. Receipt and remediation timelines are best-effort until a formal response SLA is published. Never send signing keys or passwords. See `docs/THREAT_MODEL.md` and `docs/SECURITY_CHECKLIST.md` for the current security boundary.
